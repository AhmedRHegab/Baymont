# IIS / Kestrel deployment (Windows operations PC)

## Prerequisites

1. .NET 10 ASP.NET Core Hosting Bundle
2. SQLite: no service to install. DB file lives in `publish\App_Data\baymont.db`; give the app-pool identity modify rights on `App_Data`. Install `sqlite3.exe` for backups
3. IIS with ASP.NET Core Module V2

## Publish

```powershell
cd C:\baymont\system\frontend
npm ci
npm run build

cd C:\baymont\system\backend
dotnet publish Baymont.Api\Baymont.Api.csproj -c Release -o C:\baymont\publish
```

`npm run build` writes the SPA into `Baymont.Api/wwwroot`.

## IIS site

1. Create application pool: **No Managed Code**, Integrated.
2. Create site bound to LAN IP (or `baymont.local`) on port 80/443.
3. Physical path: `C:\baymont\publish`
4. Ensure `web.config` generated by publish is present.

## Firewall

- Allow inbound TCP 80/443 **only** from village LAN subnet (example `192.168.10.0/24`).
- Do not publish the site to the internet / WAN.

## Kestrel alternative

```powershell
dotnet Baymont.Api.dll --urls http://0.0.0.0:5080
```

Register with NSSM or a Windows Service, then reverse-proxy via IIS if desired.

## First login

- User: `admin`
- Password: `ChangeMe!123` (force change on first login recommended)
- Gate search user: `gate` / `GateSearch!123`
