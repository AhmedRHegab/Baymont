# دليل التشغيل — نظام باي مونت السخنة

## التشغيل اليومي

1. جهاز غرفة العمليات يعمل باستمرار مع UPS.
2. خدمات Windows: IIS (أو خدمة Kestrel) — قاعدة البيانات ملف SQLite محلي بدون خادم.
3. الأجهزة الأخرى تفتح المتصفح على `http://baymont.local` أو IP الخادم.

## الحسابات

| المستخدم | الدور | الاستخدام |
|----------|--------|-----------|
| admin | Admin | إدارة كاملة |
| gate | SearchOnly | بحث البوابات فقط |
| (ينشئه المدير) | Overhead | مهندس تسليم: يسجل التسليمات فقط، ويشاهد باقي النظام |

## الأقسام

- **المقاولون**: الشركة والمقاول والعمالة (صور البطاقة والفيش) والسيارات والمعدات والخامات وتواريخ الدخول والخروج.
- **التسليمات**: مهندس التسليم، العميل، الوحدة، الاستلام وسبب عدمه، الفرش، التعليقات والشكاوى.
- **المبيت**: قائمة الملاك المبيت حسب اليوم والوردية ومجمعة بالمصطبة، مع زر نسخ كنص وطباعة.
- **الموظفون**: دخول وخروج موظفي الشركة، وتقرير «المتواجدون الآن» (موظفون + مقاولون + عمالهم).
- **الورديات**: الوردية الخارجية والدورية الليلية لكل يوم.

الصور المرفوعة تُحفظ في `App_Data\uploads` ويراها المدير والمحرر فقط.

## تصاريح الزيارة (الحجوزات)

**وصول التصاريح**
- الإدارة ترسل ملف Excel بالبريد الإلكتروني (عمودان فقط: Deal Name = كود الوحدة، و Full Name = الأسماء). المفروض أن يصل يوم الجمعة، وتكون فترة التصريح من الجمعة إلى الجمعة التي تليها.
- يقرأ النظام البريد تلقائياً كل 5 دقائق ويضع الحجوزات في «الحجوزات ← بانتظار المراجعة».
- إذا وصل الملف في يوم آخر، يسجل النظام يوم وتاريخ إرسال البريد، ويفترض الفترة من **أقرب جمعة** إلى الجمعة التي تليها، ويعرض تنبيه «فترة التصريح تقديرية». على المراجع أن يتأكد من التاريخين قبل الاعتماد.
- إذا كان في عنوان الرسالة أو اسم الملف كلمة (استضافة / تأجير / سيلز / مفوض) يختار النظام نوع الزيارة تلقائياً، وإلا يختاره المراجع.
- المراجع يضغط «اعتماد» أو «رفض». لا يظهر للبوابة إلا الحجز المعتمد.

**على البوابة**
- «تسجيل دخول» و«تسجيل خروج»: يمكن تكرارهما خلال فترة التصريح، ويحفظ النظام وقت كل مرة.
- «مغادرة نهائية»: بعدها **لا يمكنه الدخول مرة أخرى** إلا بتصريح جديد يصل بالبريد.
- «تراجع» يلغي آخر تسجيل بالخطأ.
- إذا انتهى التصريح ولم تُسجل المغادرة النهائية لمن دخل، يظهر «متأخر عن المغادرة» في صفحة المتابعة.
- ضيوف الاستضافة الموجودون بالداخل يُحسبون ضمن «إجمالي من بالموقع الآن» في صفحة الموظفين.

**المتابعة**: أرقام الأسبوع (من الجمعة إلى الجمعة)، والمتأخرون، وجدول 13 أسبوعاً. صفحة «البريد» تعرض الرسائل التي قُرئت أو تُجوهلت وسبب ذلك، وفيها زر «افحص البريد الآن». الإدخال اليدوي للطوارئ متاح للمدير فقط.

## النسخ الاحتياطي

- سكربت: `deploy/backup.ps1`
- ينسخ ملف `App_Data\baymont.db` (يتطلب `sqlite3.exe`) ومجلد `uploads`
- مجدول يومياً عبر Task Scheduler
- حفظ على قرص منفصل (`D:\BaymontBackups`)
- اختبار استعادة دوري عبر `deploy/restore.ps1`

## عند تعارض التعديل (409)

يظهر تنبيه يطلب إعادة تحميل السجل قبل الحفظ مرة أخرى.

## استيراد Excel

من القائمة (للمدير فقط) ← «استيراد ملف» ← «ابدأ الاستيراد». تظهر نافذة بالتعليمات خطوة بخطوة، وفيها زر لتحميل النموذج الجاهز.

- الصيغة المقبولة: xlsx فقط، حتى 2000 سطر و5 ميجابايت.
- الأعمدة: اسم المالك، رقم الموبايل، المصطبة، المبنى، الدور، الشقة، الرقم الإنشائي.
- النظام يفحص الملف أولاً ويعرض ما سيُضاف دون حفظ، ثم يحفظ بعد الضغط على «تأكيد الاستيراد».
- لا يُحفظ أي شيء إذا وُجد خطأ في أي سطر.
- الاستيراد يضيف فقط: المالك المسجل بنفس الاسم لا يتكرر، والوحدة المسجلة (نفس الرقم الإنشائي أو نفس المصطبة/المبنى/الدور/الشقة) تُتجاهل.
