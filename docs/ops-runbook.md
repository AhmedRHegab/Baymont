# دليل التشغيل — نظام باي مونت السخنة

## التشغيل اليومي

1. جهاز غرفة العمليات يعمل باستمرار مع UPS.
2. خدمات Windows: IIS (أو خدمة Kestrel) — قاعدة البيانات ملف SQLite محلي بدون خادم.
3. الأجهزة الأخرى تفتح المتصفح على `http://baymont.local` أو IP الخادم.

## الحسابات

| المستخدم | الدور | الاستخدام |
|----------|--------|-----------|
| admin | Admin | إدارة كاملة |
| gate | SearchOnly | بحث البوابات فقط |
| (ينشئه المدير) | Overhead | مهندس تسليم: يسجل التسليمات فقط، ويشاهد باقي النظام |

## الأقسام

- **المقاولون**: الشركة والمقاول والعمالة (صور البطاقة والفيش) والسيارات والمعدات والخامات وتواريخ الدخول والخروج.
- **التسليمات**: مهندس التسليم، العميل، الوحدة، الاستلام وسبب عدمه، الفرش، التعليقات والشكاوى.
- **المبيت**: قائمة الملاك المبيت حسب اليوم والوردية ومجمعة بالمصطبة، مع زر نسخ كنص وطباعة.
- **الموظفون**: دخول وخروج موظفي الشركة، وتقرير «المتواجدون الآن» (موظفون + مقاولون + عمالهم).
- **الورديات**: الوردية الخارجية والدورية الليلية لكل يوم.

الصور المرفوعة تُحفظ في `App_Data\uploads` ويراها المدير والمحرر فقط.

## النسخ الاحتياطي

- سكربت: `deploy/backup.ps1`
- ينسخ ملف `App_Data\baymont.db` (يتطلب `sqlite3.exe`) ومجلد `uploads`
- مجدول يومياً عبر Task Scheduler
- حفظ على قرص منفصل (`D:\BaymontBackups`)
- اختبار استعادة دوري عبر `deploy/restore.ps1`

## عند تعارض التعديل (409)

يظهر تنبيه يطلب إعادة تحميل السجل قبل الحفظ مرة أخرى.

## استيراد Excel

غير مفعّل بالكامل بعد. صفحة الاستيراد تعرض رسالة stub حتى يتم ربط أعمدة الملف الفعلي.
